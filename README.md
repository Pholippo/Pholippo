### 🪟 agentfenster

Lets AI agents (Claude Code, Codex) operate Windows apps on an **invisible second desktop** — it never takes over your mouse,
checks every action against the window afterwards and reports honestly when something didn't work. No silent successes.
9,500+ automated tests. Friends beta first, public release planned for early 2027. → [agentfenster.com](https://agentfenster.com)

### 🧪 Agent Labs — the agent-* ecosystem

Tools that make AI agents more useful on a normal Windows PC, built with [@clemensjl](https://github.com/clemensjl) and
[@Fluffyduck12345](https://github.com/Fluffyduck12345). Repos are private while in development.

| App | What it does |
|---|---|
| **agentfenster** | GUI automation on a hidden desktop, driven over MCP |
| **agentshot** | Screenshot tool built for AI agents (Rust, MCP) |
| **agent-voice** | Dictation with voice calibration (fork of [Handy](https://github.com/cjpais/Handy)) |
| **agent-memory** | Shared memory layer for all agents (SQLite FTS5 + MCP) |
| **agent-hub** | Installs, updates and shows all agent-* apps in one place |
| **agent-teams / agentcall** | Agent sessions on different laptops talk to each other; humans see tasks and decisions live |
| **mitschrift** | AI class note-taker: live transcript, handwriting notebook, study mode |

### How I work

- I come up with the idea and decide how it should behave — written down as hard rules every agent reads first.

- I test on real programs and real machines, demand proof that a fix works, and chase down what doesn't.
